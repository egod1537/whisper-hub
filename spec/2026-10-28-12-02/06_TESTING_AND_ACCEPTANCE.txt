UNIT TESTS
- parsing, size/type/format/language limits
- queue transitions, FIFO ordering, attempts/backoff, expired lease recovery, heartbeat
- timestamp formatting SRT/VTT, Unicode Korean/Japanese, empty transcript
- file paths, filename normalization, safe download headers

API CONTRACT TESTS
- unauthorized 401 on job endpoints
- upload 202 then status queued, correct link paths
- invalid inputs errors 400/413/415/422
- idempotency same key/content 200, mismatch 409, cleanup on upload failure
- list cursor pagination stable with same created_at and IDs
- cancel queued and processing, conflict completed
- retry failed only
- results 409 before completion, available download types on completion
- consistent error requestId; OpenAPI contract snapshot

CONCURRENCY & RECOVERY
- simultaneously started workers never claim same job
- processing heartbeat/lease expiry, process crash then recovery
- no duplicate published result after crash
- with queued jobs 1,2,3, claim order is 1,2,3
- retry delayed job does not block eligible jobs
- processing cancellation never accidentally marks completed
- docker compose down/up maintains pending jobs and finished results
