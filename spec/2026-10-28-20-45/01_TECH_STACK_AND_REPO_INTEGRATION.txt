READ FIRST
- Existing package.json / pnpm-workspace.yaml; confirm versions and workspace wiring.
- README.md, backend/openapi.json, backend job routes, compose.yaml and .env.example.
- Follow current backend endpoint paths and request/response types rather than assuming example payloads.

STACK
- frontend/: React 19 + TypeScript strict + Vite + @blueprintjs/core v6.x + @blueprintjs/icons matching v6.x.
- Prefer stable Blueprint v6.16.0 or higher for React 19 peer compatibility; inspect current releases / lockfile and pin tested compatible versions. Avoid deprecated legacy Popover and Overlay; no requirement to use either.
- Minimal custom CSS. Import normalize and Blueprint CSS according to official package docs and confirm bundling.
- Use fetch with typed, runtime-defensive JSON parsing, AbortController. No redux, state machines, or query framework required; polling hooks are enough.
- Existing backend remains TS/Fastify. Frontend is a separate workspace package named whisper-hub-frontend.
